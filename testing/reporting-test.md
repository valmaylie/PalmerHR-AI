# Pengujian HR Reporting Agent

## Tujuan
Menyusun draf laporan HRD berdasarkan data yang tersedia dan menyatakan keterbatasan sumber.

## Prompt
```text
Baca skill hr-monthly-report.
Buat draf laporan HRD berdasarkan examples/data_karyawan_fiktif.csv.
Sajikan ringkasan kehadiran, kondisi data, temuan, keterbatasan,
dan rekomendasi tindak lanjut. Jangan mengarang data.
```

## Kriteria evaluasi
- [ ] Angka sesuai data sumber.
- [ ] Periode dan cakupan data dijelaskan.
- [ ] Data yang tidak tersedia tidak diada-adakan.
- [ ] Fakta dibedakan dari interpretasi.
- [ ] Laporan dinyatakan sebagai draf yang perlu diverifikasi HRD.

## Catatan pengujian
Pemilik proyek melaporkan pengujian berhasil melalui OpenCode. Tambahkan screenshot keluaran aktual.
