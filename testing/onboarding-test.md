# Pengujian Employee Onboarding Agent

## Tujuan
Menyusun checklist penerimaan karyawan baru sesuai jabatan/unit dan kebijakan yang diberikan.

## Prompt
```text
Baca skill employee-onboarding.
Buat checklist onboarding untuk karyawan baru posisi Admin Kebun
di perusahaan kelapa sawit. Kelompokkan aktivitas sebelum hari pertama,
hari pertama, dan masa orientasi. Tandai item yang perlu konfirmasi HRD.
```

## Kriteria evaluasi
- [ ] Checklist dibagi berdasarkan tahapan.
- [ ] Penanggung jawab dicantumkan jika diketahui.
- [ ] K3/orientasi keselamatan disesuaikan dengan lokasi dan jabatan.
- [ ] Agent tidak mengklaim pelatihan selesai tanpa bukti.
- [ ] Item yang bergantung pada kebijakan perusahaan ditandai untuk konfirmasi.

## Catatan pengujian
Pemilik proyek melaporkan pengujian berhasil melalui OpenCode. Tambahkan screenshot keluaran aktual.
