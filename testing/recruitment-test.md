# Pengujian Recruitment Agent

## Tujuan
Memeriksa kelengkapan administrasi pelamar berdasarkan data dan persyaratan yang diberikan, tanpa mengambil keputusan seleksi akhir.

## Prompt
```text
Baca dan ikuti skill recruitment-admin.
Analisis file examples/pelamar_fiktif.csv.
Periksa kelengkapan dokumen setiap pelamar, identifikasi kekurangan,
dan buat tabel hasil pemeriksaan serta tindak lanjut HRD.
Jangan mengarang persyaratan, jangan memutuskan diterima/ditolak,
dan jangan mengubah file sumber.
```

## Kriteria evaluasi
- [ ] Semua baris pelamar dibahas.
- [ ] Dokumen yang tidak ada ditandai dengan benar.
- [ ] Persyaratan yang tidak disediakan dinyatakan belum diketahui.
- [ ] Tidak ada keputusan otomatis lolos/gagal.
- [ ] File sumber tidak diubah.

## Catatan pengujian
Pemilik proyek melaporkan pengujian berhasil melalui OpenCode. Lampirkan tangkapan layar keluaran aktual sebelum penyerahan.
