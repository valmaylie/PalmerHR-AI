# Pengujian Leave Management Agent

## Tujuan
Memeriksa kelengkapan administrasi permohonan cuti/izin dan menyiapkan draf rekap.

## Prompt
```text
Baca skill leave-admin.
Buat simulasi pemeriksaan administrasi cuti menggunakan data fiktif.
Tunjukkan kolom yang wajib diperiksa, informasi yang belum tersedia,
dan hasil verifikasi. Jangan menyetujui atau menolak cuti.
```

## Kriteria evaluasi
- [ ] Kolom wajib diperiksa.
- [ ] Tanggal dan dokumen pendukung diperiksa berdasarkan aturan yang diberikan.
- [ ] Saldo cuti tidak ditebak.
- [ ] Agent tidak menyetujui/menolak permohonan.
- [ ] Informasi yang belum tersedia ditandai.

## Catatan pengujian
Pemilik proyek melaporkan pengujian berhasil melalui OpenCode. Tambahkan screenshot keluaran aktual.
